# 板块盯盘轮播

## 它做什么

- **位置**：挂在 `shell.bottom`，即窗口最底部独占一行，右对齐。
  金价插件在 `conversation.composer.dock`（输入框下方那行），两者因此是**上下两行**。
  （`composer.dock` 的 CSS 是 `display:flex; align-items:center` 且无 `flex-wrap`，
  结构上只能并排，放不下第二行，所以板块条改挂底部槽位。）
- **轮动**：每 3.5 秒换一项，单行显示 `代码 up/down 幅度%`；
  1 分钟变化 ≥0.15% 时补 `1m up/down 幅度%`。
- **拼音代号**：屏幕上不出现汉字。

  | 大盘 | | 主题 | |
  |---|---|---|---|
  | SH 上证 · SZ 深证 · CYB 创业板 · KC50 科创50 · HS300 沪深300 | | CPO · XP 芯片 · AI · TX 通信 · JG 军工 · HT 航天 · YY 医药 · YH 银行 · YX 游戏 · YL 娱乐 · XNY 新能源 · BJ 白酒 |

- **异动**：最近一次重大异动在 40 秒内时暂停轮动，前面加闪烁红点。
- **开关**：行尾下拉框（插件 / 弹窗 / 静默），鼠标悬停才浮现。

## 展示方式开关

| 模式 | 行为 |
|---|---|
| **插件**（默认） | 右下角轮动可见 |
| **弹窗** | 隐藏，异动时弹桌面浮层 |
| **静默** | 都不显示，只留一个 26×3 像素的小凸起，点一下回到插件 |

**飞书私信不受影响**，三档都会推。

## 数据来源

每 3 秒请求 `http://127.0.0.1:8787/api/state`，该接口由 `sector-watch.mjs --watch`
监听在回环地址，`watch` 字段返回 5 个大盘 + 12 个自选主题的当日涨跌与 1 分钟变化。
名单在 `sector-watch.mjs` 的 `WATCH_THEMES` / `WATCH_INDEXES` 里改，
用 `node sector-watch.mjs --watchlist` 可以检查名称是否匹配到板块。

## 限制

- 只对本机 `127.0.0.1:8787` 生效，换台机器打开页面会不显示。
- 数据跟随盯盘器扫描节奏（30 秒刷新一次快照），不是逐笔行情。
- 只显示当日涨跌与 1 分钟变化，不含净值、持仓、盈亏。
